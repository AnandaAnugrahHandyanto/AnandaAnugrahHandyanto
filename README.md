## Tentang Saya

Saya adalah seorang Backend Engineer yang fokus pada pengembangan sistem manajemen berbasis web menggunakan ekosistem PHP dan framework Laravel. Melalui status saya sebagai **GitHub Developer Program Member**, saya senang mengeksplorasi integrasi API, sistem autentikasi OAuth yang aman, serta manajemen basis data terstruktur. Proyek utama yang sedang saya kembangkan saat ini adalah **Sistem Absensi Pesantren**, sebuah solusi digital yang dirancang untuk mengoptimalkan operasional dan alur kerja di institusi pendidikan Islam secara efisien dan *real-time*.
